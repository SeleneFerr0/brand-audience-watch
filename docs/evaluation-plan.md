# 任务与评估计划

本文定义研究设计，尚未实施实验。

## 任务 A：品牌与人群匹配

输入：品牌/产品/概念、目标市场、可用人群特征、历史行为与时间范围。
输出：人群匹配排序、需求与场景解释、规模估计及不确定性。

基线包括类别购买倾向、可解释的回归/树模型、内容相似度；再比较双塔与共享表示。衡量 PR-AUC、排序、概率校准、分群稳定性。人群规模只有在抽样框、权重、可触达范围和重叠处理明确时才可外推。

## 任务 B：营销增量

估计相同人群在指定营销干预与未干预条件下结果期望的差异。数据必须明确分配单位、treatment、outcome、观察窗口，以及在适用情形下的分配概率。

优先用随机对照数据建立基准，检查样本与实验质量。使用 uplift/Qini、AUUC、策略增量价值、预算约束下净收益与置信区间，不仅比较转化预测 AUC。不同数据集的这些数值不直接混排。观察性数据的因果结论需要额外识别假设及敏感性分析。

## 任务 C：爆品与新概念预测

首先定义“爆”：指定市场、品类、时间、门槛与推广情景。例如首发 90 天的目标销量、渗透率、复购率或品类内相对增速。不同定义是不同任务。

区分三个层次：

1. 已上市产品：利用实时需求信号预测趋势与持续性。
2. 未上市但已描述的产品：根据属性、类似品、价格、渠道与概念测试预测采用和需求。
3. 尚未形成的产品：从未满足需求提出候选概念，再执行第二层验证；不能把生成概念当作已确认的未来爆品。

预测输出包括明确情景下的成功概率、需求区间、目标受众、替代对象、关键假设与证据缺口。

### 离线回测

- 按历史发布时间滚动回测，包含失败、下架和低销量产品，避免幸存者偏差。
- 零历史测试只能使用当时上线前已知的材料；含早期反馈的测试另设 7/14/30 天信息窗口。
- 按新品、品牌或概念家族隔离必要的测试集，检查近重复与同系列泄漏。
- 已上市趋势模型与上线前预测分别比较；外部预训练模型和知识来源记录版本与时间，可能见过测试对象时不得称作干净的历史预测。
- 与历史成功率、相似品迁移、简单增长模型及可解释监督模型比较；有时间序列证据时再加入基础预测模型。

### 指标

- 爆品筛选：Precision@K、Recall@K、PR-AUC、Brier score 与概率校准；报告基准发生率。
- 数量预测：MAE、适用层级的聚合误差、分位数损失、区间覆盖率与宽度；避免对零销量直接使用普通 MAPE。
- 业务决策：验证预算下发现成功概念的数量、误判成本、提前量、蚕食与新增价值。
- 上市前概念：真实受众的竞争选择、价格敏感性、试用与复购；采用前瞻测试验证。

## 共享数据规则

事件与数据可得时间分开记录；特征仅来自决策当时可得的信息。区分曝光、偏好、购买、供给、渠道与干预。记录样本来源和权重，不直接把评论者、线上用户或面板样本当作总体市场。记录数据、模型、概念、特征及实验版本，支持复现和审计。
