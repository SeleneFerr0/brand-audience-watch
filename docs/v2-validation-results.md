|---|---:|---:|

在本小类目开发回测中，NB 的分位数误差较低，hurdle 的中位数误差较低。字符文本给 NB 的 pinball 改善约 0.000208，给 hurdle 的中位数 MAE 改善约 0.001667，幅度很小；quantile 模型加入文本反而略差。尚不支持增加复杂文本模型的必要性或宣称普遍优胜。

Poisson/NB/hurdle 的默认 point 为期望值，quantile/Chronos 的 point 为中位数。因此表中统一使用 `macro_mae_median`；均值 point 的 MAE 单独保留，不能混用。例如 hurdle/字符的均值 MAE 为 0.339791，高于零基线 0.261667，而其中位数 MAE 为 0.219583。稀疏分布下，这些结果并不矛盾。

全部分数、逐 lead 区间覆盖/宽度、原生概率模型的 Brier/NLL 与后端状态在运行目录；导出的 evidence JSON 含紧凑 leaderboard。当前是开发回测，产品/时期存在依赖，未作独立样本显著性声明，也未建立真实爆品定义或销售指标。
